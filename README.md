# Homebrew Tap for EdgeControl

[EdgeControl](https://github.com/kemalandic/edgecontrol) — Native macOS system dashboard that turns any display into a fully customizable monitoring station.

## Install

```bash
brew tap kemalandic/edgecontrol
brew install --cask edgecontrol
```

## Upgrade

```bash
brew upgrade --cask edgecontrol
```

## Uninstall

```bash
brew uninstall --cask edgecontrol
brew untap kemalandic/edgecontrol
```
